# There are two ways to install!
## Portable
Download it from the releases
## Install
Open powershell as an admin, type in `Invoke-WebRequest -Uri "https://github.com/CaptainFriscoman/NamePyTracker/releases/download/Release/datatracker.exe" -OutFile "PyTracker.exe"` and then type in `PyTracker` to open it.
